# `rum.ext.music.node`

## Classes

### `Node`

```python
class Node(*, pool: NodePool, host: str, port: int, password: str, identifier: str | None = None, secure: bool = False, server_type: ServerType | str = <ServerType.LAVALINK: lavalink>, session: Session | None = None, heartbeat: float = 30.0, resume_timeout: int = 60) -> None
```

Connection to a Lavalink v4 or NodeLink v3 server.

Handles the WebSocket session, REST requests, and dispatching player/node events through `rum.ext.music.NodePool`. Select protocol behavior with `server_type` (`"lavalink"` or `"nodelink"`).

#### `connect()`

```python
connect() -> None
```

Open the WebSocket connection and start listening for events.

#### `disconnect()`

```python
disconnect() -> None
```

Close the WebSocket/session and mark the node unavailable.

#### `request()`

```python
request(method: str, path: str, *, raw: bool = False, **kwargs: Any) -> Any
```

Perform an authenticated REST request against the node.

Returns decoded JSON by default, `None` for 204, or raw `bytes` when `raw=True`.
