# `rum.ext.music.queue`

## Classes

### `Queue`

```python
class Queue(*, max_size: int | None = None) -> None
```

Default in-memory track queue for `rum.ext.music.Player`.

A custom queue provider can be used instead by passing a compatible object to `Player(..., queue=...)`. At minimum, a player expects `loop_mode` (`None`, `"track"`, or `"queue"`) and `get() -> Track` that raises `rum.ext.music.QueueEmpty` when no track is available.
