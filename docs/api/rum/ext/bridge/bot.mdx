### `Bot`

```python
class Bot(command_prefix: str | Iterable[str] | Callable[[Bot | AutoShardedBot, Message], str | Iterable[str] | Coroutine[Any, Any, str | Iterable[str]]] = <function when_mentioned at 0x70de7296f480>, help_command: HelpCommand | None = ..., **options)
```

Represents a discord bot, with support for cross-compatibility between command types.

This class is a subclass of `.ext.commands.Bot` and as a result anything that you can do with a `.ext.commands.Bot` you can do with this bot.

*Added in 2.0.*
