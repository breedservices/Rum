# `rum.monetization`

## Classes

### `Entitlement`

```python
class Entitlement(*, data: EntitlementPayload, state: ConnectionState) -> None
```

Represents a Discord entitlement.

*Added in 2.5.*

> [!NOTE]
> As of October 1, 2024, entitlements that have been purchased will have `ends_at` set to `None` unless the parent `Subscription` has been cancelled.
>
> [See the Discord changelog.](https://docs.discord.com/developers/change-log#premium-apps-entitlement-migration-and-new-subscription-api)

#### Attributes

id: `int`  
The entitlement's ID.

sku_id: `int`  
The ID of the SKU this entitlement is for.

application_id: `int`  
The ID of the application this entitlement belongs to.

user_id: `int` | `MISSING`  
The ID of the user that owns this entitlement.

type: `EntitlementType`  
The type of entitlement.

deleted: `bool`  
Whether the entitlement has been deleted.

starts_at: `datetime.datetime` | `MISSING`  
When the entitlement starts.

ends_at: `datetime.datetime` | `MISSING`  
When the entitlement expires.

guild_id: `int` | `MISSING`  
The ID of the guild that owns this entitlement.

consumed: `bool`  
Whether or not this entitlement has been consumed. This will always be `False` for entitlements that are not from an SKU of type `SKUType.consumable`.

#### `consume()`

```python
consume() -> None
```

*(coroutine)*

Consumes this entitlement.

This can only be done on entitlements from an SKU of type `SKUType.consumable`.

#### Raises

HTTPException  
Consuming the entitlement failed.

#### `delete()`

```python
delete() -> None
```

*(coroutine)*

Deletes a test entitlement.

A test entitlement is an entitlement that was created using `Guild.create_test_entitlement` or `User.create_test_entitlement`.

#### Raises

HTTPException  
Deleting the entitlement failed.

#### `fetch_subscriptions()`

```python
fetch_subscriptions(user: Snowflake, *, before: SnowflakeTime | None = None, after: SnowflakeTime | None = None, limit: int | None = 100) -> SubscriptionIterator
```

Returns an `.AsyncIterator` that enables fetching the SKU's subscriptions.

*Added in 2.7.*

#### Parameters

user: `.abc.Snowflake`  
The user for which to retrieve subscriptions.

before: `.abc.Snowflake` | `datetime.datetime` | None  
Retrieves subscriptions before this date or object. If a datetime is provided, it is recommended to use a UTC-aware datetime. If the datetime is naive, it is assumed to be local time.

after: `.abc.Snowflake` | `datetime.datetime` | None  
Retrieve subscriptions after this date or object. If a datetime is provided, it is recommended to use a UTC-aware datetime. If the datetime is naive, it is assumed to be local time.

limit: `int` | None  
The number of subscriptions to retrieve. If `None`, retrieves all subscriptions.

#### Yields

`Subscription`  
A subscription that the user has for this SKU.

#### Raises

`HTTPException`  
Getting the subscriptions failed.

#### Examples

Usage :

    async for subscription in sku.fetch_subscriptions(discord.Object(id=123456789)):
        print(subscription.status)

Flattening into a list :

    subscriptions = await sku.fetch_subscriptions(discord.Object(id=123456789)).flatten()
    # subscriptions is now a list of Subscription...

All parameters except for `user` are optional.

### `Subscription`

```python
class Subscription(*, state: ConnectionState, data: SubscriptionPayload) -> None
```

Represents a user making recurring payments for one or more SKUs.

Successful payments grant the user access to entitlements associated with the SKU.

*Added in 2.7.*

#### Attributes

id: `int`  
The subscription's ID.

user_id: `int`  
The ID of the user that owns this subscription.

sku_ids: List\[`int`\]  
The IDs of the SKUs this subscription is for.

entitlement_ids: List\[`int`\]  
The IDs of the entitlements this subscription is for.

renewal_sku_ids: List\[`int`\]  
The IDs of the SKUs that the buyer will be subscribed to at renewal.

current_period_start: `datetime.datetime`  
The start of the current subscription period.

current_period_end: `datetime.datetime`  
The end of the current subscription period.

status: `SubscriptionStatus`  
The status of the subscription.

canceled_at: `datetime.datetime` | `None`  
When the subscription was canceled.
