#### `interaction_check()`

```python
interaction_check(interaction: Interaction) -> bool
```

*(coroutine)*

A callback that is called when an interaction happens within the view that checks whether the view should process item callbacks for the interaction.

This is useful to override if, for example, you want to ensure that the interaction author is a given user.

The default implementation of this returns `True`.

If this returns `False`, `on_check_failure` is called.

> [!NOTE]
> If an exception occurs within the body then the check is considered a failure and `on_error` is called.

#### Parameters

interaction: `discord.Interaction`  
The interaction that occurred.

#### Returns

`bool`  
Whether the view children's callbacks should be called.

### `DesignerView`

```python
class DesignerView(*items: ViewItem[V], timeout: float | None = 180.0, disable_on_timeout: bool = False, store: bool = True)
```

Represents a UI view compatible with v2 components.

This object must be inherited to create a UI within Discord.

*Added in 2.7.*

#### Parameters

\*items: `ViewItem`  
The initial items attached to this view.

timeout: `float` | `None`  
Timeout in seconds from last interaction with the UI before no longer accepting input. Defaults to 180.0. If `None` then there is no timeout.

store: `bool` | `None`  
Whether this view should be stored for callback listening. Setting it to `False` will ignore item callbacks and prevent their values from being refreshed. Defaults to `True`.

#### Attributes

timeout: `float` | `None`  
Timeout from last interaction with the UI before no longer accepting input. If `None` then there is no timeout.

children: List\[`ViewItem`\]  
The list of items attached to this view.

disable_on_timeout: `bool`  
Whether to disable the view's items when the timeout is reached. Defaults to `False`.

message: `.Message` | `None`  
The message that this view is attached to. If `None` then the view has not been sent with a message.

parent: `.Interaction` | `None`  
The parent interaction which this view was sent from. If `None` then the view was not sent using `InteractionResponse.send_message`.

#### `from_message()`

```python
from_message(message: Message, /, *, timeout: float | None = 180.0) -> View
```

Converts a message's components into a `DesignerView`.

The `.Message.components` of a message are read-only and separate types from those in the `discord.ui` namespace. In order to modify and edit message components they must be converted into a `View` first.

#### Parameters

message: `.Message`  
The message with components to convert into a view.

timeout: `float` | `None`  
The timeout of the converted view.

#### Returns

`View`  
The converted view. This always returns a `View` and not one of its subclasses.

### `View`

```python
class View(*items: ViewItem[V], timeout: float | None = 180.0, disable_on_timeout: bool = False, store: bool = True)
```

Represents a legacy UI view for V1 components `discord.ui.Button` and `discord.ui.Select`.

This object must be inherited to create a UI within Discord.

*Added in 2.0.*

*Changed in 2.7

Now inherits from `BaseView`.*

\*items: `ViewItem`  
The initial items attached to this view.

timeout: `float` | `None`  
Timeout in seconds from last interaction with the UI before no longer accepting input. Defaults to 180.0. If `None` then there is no timeout.

store: `bool` | `None`  
Whether this view should be stored for callback listening. Setting it to `False` will ignore item callbacks and prevent their values from being refreshed. Defaults to `True`.

#### Attributes

timeout: `float` | `None`  
Timeout from last interaction with the UI before no longer accepting input. If `None` then there is no timeout.

children: List\[`ViewItem`\]  
The list of children attached to this view.

disable_on_timeout: `bool`  
Whether to disable the view when the timeout is reached. Defaults to `False`.

message: `.Message` | `None`  
The message that this view is attached to. If `None` then the view has not been sent with a message.

parent: `.Interaction` | `None`  
The parent interaction which this view was sent from. If `None` then the view was not sent using `InteractionResponse.send_message`.
