# `rum.ui.section`

## Classes

### `Section`

```python
class Section(*items: ViewItem, accessory: ViewItem = None, id: int | None = None)
```

Represents a UI section. Sections must have 1-3 (inclusive) items and an accessory set.

*Added in 2.7.*

#### Parameters

\*items: `ViewItem`  
The initial items contained in this section, up to 3. Currently only supports `discord.ui.TextDisplay`. Sections must have at least 1 item before being sent.

accessory: `ViewItem` | `None`  
The section's accessory. This is displayed in the top right of the section. Currently only supports `discord.ui.Button` and `discord.ui.Thumbnail`. Sections must have an accessory attached before being sent.

id: `int` | `None`  
The section's ID.

#### Attributes

items: List\[`ViewItem`\]  
The list of items in this section.

accessory: `ViewItem`  
The section's accessory, displayed in the top right of the section.

#### `add_item()`

```python
add_item(item: ViewItem) -> Self
```

Adds an item to the section.

#### Parameters

item: `ViewItem`  
The item to add to the section.

#### Raises

TypeError  
An `ViewItem` was not passed.

ValueError  
Maximum number of items has been exceeded (3).

#### `remove_item()`

```python
remove_item(item: ViewItem | str | int) -> Self
```

Removes an item from the section. If an `int` or `str` is passed, the item will be removed by Item `id` or `custom_id` respectively.

#### Parameters

item: `ViewItem` | `int` | `str`  
The item, item `id`, or item `custom_id` to remove from the section.

#### `get_item()`

```python
get_item(id: int | str) -> ViewItem | None
```

Get an item from this section. Alias for <span class="title-ref">utils.get(section.walk_items(), ...)</span>. If an `int` is provided, it will be retrieved by `id`, otherwise it will check the accessory's `custom_id`.

#### Parameters

id: `str` | `int`  
The id or custom_id of the item to get.

#### Returns

`ViewItem` | `None`  
The item with the matching `id` if it exists.

#### `set_accessory()`


Set an item as the section's `accessory`.

The item to set as accessory. Currently only supports `discord.ui.Button` and `discord.ui.Thumbnail`.

#### Raises

An `ViewItem` was not passed.

#### `set_thumbnail()`

```python
set_thumbnail(url: str, *, description: str | None = None, spoiler: bool = False, id: int | None = None) -> Self
```

Sets a `Thumbnail` with the provided URL as the section's `accessory`.

#### Parameters

url: `str`  
The url of the thumbnail.

description: `str` | `None`  
The thumbnail's description, up to 1024 characters.

spoiler: `bool` | `None`  
Whether the thumbnail has the spoiler overlay. Defaults to `False`.

id: `int` | `None`  
The thumbnail's ID.
