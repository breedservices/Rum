# `rum.ui.container`

## Classes

### `Container`

```python
class Container(*items: ViewItem, colour: int | Colour | None = None, color: int | Colour | None = None, spoiler: bool = False, id: int | None = None)
```

Represents a UI Container.

The current items supported are as follows:

- `discord.ui.ActionRow`
- `discord.ui.Section`
- `discord.ui.TextDisplay`
- `discord.ui.MediaGallery`
- `discord.ui.File`
- `discord.ui.Separator`

*Added in 2.7.*

#### Parameters

\*items: `ViewItem`  
The initial items in this container.

colour: `Colour` | `int`  
The accent colour of the container. Aliased to `color` as well.

spoiler: `bool` | `None`  
Whether this container has the spoiler overlay.

id: `int` | `None`  
The container's ID.

#### Attributes

items: List\[`ViewItem`\]  
The list of items in this container.

#### `add_item()`

```python
add_item(item: ViewItem) -> Self
```

Adds an item to the container.

#### Parameters

item: `ViewItem`  
The item to add to the container.

#### Raises

TypeError  
A `ViewItem` was not passed.

#### `remove_item()`

```python
remove_item(item: ViewItem | str | int) -> Self
```

Removes an item from the container. If an int or str is passed, it will remove by Item `id` or `custom_id` respectively.

#### Parameters

item: `ViewItem` | `int` | `str`  
The item, `id`, or item `custom_id` to remove from the container.

#### `get_item()`

```python
get_item(id: str | int) -> ViewItem | None
```

Get an item from this container. Roughly equivalent to <span class="title-ref">utils.get(container.items, ...)</span>. If an `int` is provided, the item will be retrieved by `id`, otherwise by `custom_id`. This method will also search for nested items.

#### Parameters

id: `str` | `int`  
The id or custom_id of the item to get.

#### Returns

`ViewItem` | `None`  
The item with the matching `id` or `custom_id` if it exists.

#### `add_row()`

```python
add_row(*items: ViewItem, id: int | None = None) -> Self
```

Adds an `ActionRow` to the container.

To append a pre-existing `ActionRow`, use `add_item` instead.

#### Parameters

\*items: `Button` | `Select`  
The items this action row contains.

id: `int` | `None`  
The action row's ID.

#### `add_section()`

```python
add_section(*items: ViewItem, accessory: ViewItem, id: int | None = None) -> Self
```

Adds a `Section` to the container.

To append a pre-existing `Section`, use the `add_item` method, instead.

#### Parameters

\*items: `ViewItem`  
The items contained in this section, up to 3. Currently only supports `discord.ui.TextDisplay`.

accessory: `ViewItem` | `None`  
The section's accessory. This is displayed in the top right of the section. Currently only supports `discord.ui.Button` and `discord.ui.Thumbnail`.

id: `int` | `None`  
The section's ID.
