# `rum.ui.media_gallery`

## Classes

### `MediaGallery`

```python
class MediaGallery(*items: MediaGalleryItem, id: int | None = None)
```

Represents a UI Media Gallery. Galleries may contain up to 10 `MediaGalleryItem` objects.

*Added in 2.7.*

#### Parameters

\*items: `discord.MediaGalleryItem`  
The initial items contained in this gallery, up to 10.

id: `int` | `None`  
The gallery's ID.

#### `append_item()`

```python
append_item(item: MediaGalleryItem) -> Self
```

Adds a `MediaGalleryItem` to the gallery.

#### Parameters

item: `MediaGalleryItem`  
The gallery item to add to the gallery.

#### Raises

TypeError  
A `MediaGalleryItem` was not passed.

ValueError  
Maximum number of items has been exceeded (10).

#### `add_item()`

```python
add_item(url: str, *, description: str = None, spoiler: bool = False) -> Self
```

Adds a new media item to the gallery.

#### Parameters

url: `str`  
The URL of the media item. This can either be an arbitrary URL or an `attachment://` URL.

description: `str` | `None`  
The media item's description, up to 1024 characters.

spoiler: `bool` | `None`  
Whether the media item has the spoiler overlay.

#### Raises

ValueError  
Maximum number of items has been exceeded (10).

#### `remove_item()`

```python
remove_item(index: int) -> Self
```

Removes an item from the gallery.

#### Parameters

index: `int`  
The index of the item to remove from the gallery.
