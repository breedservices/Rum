### `BanGuard`

```python
class BanGuard(*, limit: int = 10000, window: float = 600.0) -> None
```

Counts the responses Discord counts towards an IP ban.

Discord bans an IP that sends 10,000 invalid requests within ten minutes. The guard counts the responses Discord counts, holds the client back before the limit is reached, and stops the client outright once the token was rejected.

#### Parameters

limit: `int`  
How many counted responses are allowed in the window.

window: `float`  
The length of the window in seconds.
