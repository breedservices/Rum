# `rum.collectibles`

## Classes

### `Collectibles`

```python
class Collectibles(data: rum.types.collectibles.Collectibles, state: ConnectionState) -> None
```

Represents a user or member's equipped collectibles.

*Added in 2.8.*

<div class="describe">

</div>
