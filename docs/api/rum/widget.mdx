# `rum.widget`

## Classes

### `Widget`

```python
class Widget(*, state: ConnectionState, data: WidgetPayload) -> None
```

Represents a `Guild` widget.

<div class="container operations">

<div class="describe">

x == y

Checks if two widgets are the same.

</div>

<div class="describe">

x != y

Checks if two widgets are not the same.

</div>

<div class="describe">

str(x)

Returns the widget's JSON URL.

</div>

</div>

#### Attributes

id: `int`  
The guild's ID.

name: `str`  
The guild's name.

channels: List\[`WidgetChannel`\]  
The accessible voice channels in the guild.

members: List\[`Member`\]  
The online members in the server. Offline members do not appear in the widget.

> [!NOTE]
> Due to a Discord limitation, if this data is available the users will be "anonymized" with linear IDs and discriminator information being incorrect. Likewise, the number of members retrieved is capped.

#### `fetch_invite()`

```python
fetch_invite(*, with_counts: bool = True) -> Invite
```

*(coroutine)*

Retrieves an `Invite` from the widget's invite URL. This is the same as `Client.fetch_invite`; the invite code is abstracted away.

#### Parameters

with_counts: `bool`  
Whether to include count information in the invite. This fills the `Invite.approximate_member_count` and `Invite.approximate_presence_count` fields.

#### Returns

`Invite`  
The invite from the widget's invite URL.
