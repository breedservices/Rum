# `rum.invite`

## Classes

### `Invite`

```python
class Invite(*, state: ConnectionState, data: InvitePayload | IncompleteInvitePayload, guild: PartialInviteGuild | Guild | None = None, channel: PartialInviteChannel | GuildChannel | None = None)
```

Represents a Discord `Guild` or `abc.GuildChannel` invite.

Depending on the way this object was created, some of the attributes can have a value of `None`.

#### Attributes

max_age: `int`  
How long before the invite expires in seconds. A value of `0` indicates that it doesn't expire.

code: `str`  
The URL fragment used for the invite.

guild: `Guild` | `Object` | `PartialInviteGuild` | `None`  
The guild the invite is for. Can be `None` if it's from a group direct message.

revoked: `bool`  
Indicates if the invite has been revoked.

created_at: `datetime.datetime`  
An aware UTC datetime object denoting the time the invite was created.

temporary: `bool`  
Indicates that the invite grants temporary membership. If `True`, members who joined via this invite will be kicked upon disconnect.

uses: `int`  
How many times the invite has been used.

max_uses: `int`  
How many times the invite can be used. A value of `0` indicates that it has unlimited uses.

inviter: `User` | `None`  
The user who created the invite.

approximate_member_count: `int` | `None`  
The approximate number of members in the guild.

approximate_presence_count: `int` | `None`  
The approximate number of members currently active in the guild. This includes idle, dnd, online, and invisible members. Offline members are excluded.

expires_at: `datetime.datetime` | `None`  
The expiration date of the invite. If the value is `None` when received through <span class="title-ref">Client.fetch_invite</span> with <span class="title-ref">with_expiration</span> enabled, the invite will never expire.

*Added in 2.0.*

channel: `abc.GuildChannel` | `Object` | `PartialInviteChannel`  
The channel the invite is for.

target_type: `InviteTarget`  
The type of target for the voice channel invite.

*Added in 2.0.*

target_user: `User` | `None`  
The user whose stream to display for this invite, if any.

*Added in 2.0.*

target_application: `PartialAppInfo` | `None`  
The embedded application the invite targets, if any.

*Added in 2.0.*

scheduled_event: `ScheduledEvent` | `None`  
The scheduled event linked with the invite.

roles: List\[`Role` | `Object`\]  
The roles that will be assigned to a user that joins via this invite.

When using <span class="title-ref">Client.fetch_invite</span>, these may be partial role objects and have nullish attributes.

*Added in 2.8.*

#### `edit_target_users()`

```python
edit_target_users(target_users_file: File) -> None
```

*(coroutine)*

Updates the target users list for this invite.

You must have created this invite or have the `Permissions.manage_guild` permission to do this.

You can use `utils.users_to_csv` to generate a virtual CSV file from a sequence of user IDs.

#### Parameters

target_users_file: `File`  
A CSV file with a single column of user IDs for all the users able to accept this invite.

#### Raises

HTTPException  
Updating the target users failed.

Forbidden  
You do not have permissions to edit this invite.

NotFound  
The invite is invalid or expired.

#### `fetch_target_users_job_status()`

```python
fetch_target_users_job_status() -> InviteTargetUsersJobStatus
```

*(coroutine)*

Retrieves the status of the target users processing job for this invite.

You must have created this invite or have the `Permissions.manage_guild` or `Permissions.view_audit_log` permissions. permission to do this.

#### Returns

`InviteTargetUsersJobStatus`  
The job status information.

#### Raises

HTTPException  
Fetching the job status failed.

NotFound  
The invite is invalid or expired.

Forbidden  
You do not have permission to view the target users.

#### `delete()`

```python
delete(*, reason: str | None = None)
```

*(coroutine)*

Revokes the instant invite.

You must have the `Permissions.manage_channels` permission to do this.

#### Parameters

reason: `str` | `None`  
The reason for deleting this invite. Shows up on the audit log.

#### Raises

Forbidden  
You do not have permissions to revoke invites.

NotFound  
The invite is invalid or expired.

HTTPException  
Revoking the invite failed.

#### `set_scheduled_event()`

```python
set_scheduled_event(event: ScheduledEvent) -> None
```

Links the given scheduled event to this invite.

> [!NOTE]
> Scheduled events aren't actually associated with invites on the API. Any guild channel invite can have an event attached to it. Using `abc.GuildChannel.create_invite`, `Client.fetch_invite`, or this method, you can link scheduled events.

*Added in 2.0.*

#### Parameters

event: `ScheduledEvent`  
The scheduled event object to link.
