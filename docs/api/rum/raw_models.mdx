# `rum.raw_models`

## Classes

### `AutoModActionExecutionEvent`

```python
class AutoModActionExecutionEvent(state: ConnectionState, data: AutoModActionExecution) -> None
```

Represents the payload for an `on_auto_moderation_action_execution`

*Added in 2.0.*

#### Attributes

action: `AutoModAction`  
The action that was executed.

rule_id: `int`  
The ID of the rule that the action belongs to.

rule_trigger_type: `AutoModTriggerType`  
The category of trigger the rule belongs to.

*Added in 2.4.*

guild_id: `int`  
The ID of the guild that the action was executed in.

guild: `Guild` | `None`  
The guild that the action was executed in, if cached.

user_id: `int`  
The ID of the user that triggered the action.

member: `Member` | `None`  
The member that triggered the action, if cached.

channel_id: `int` | `None`  
The ID of the channel in which the member's content was posted.

channel: `TextChannel` | `Thread` | `VoiceChannel` | `StageChannel` | `None`  
The channel in which the member's content was posted, if cached.

message_id: `int` | `None`  
The ID of the message that triggered the action. This is only available if the message was not blocked.

message: `Message` | `None`  
The message that triggered the action, if cached.

alert_system_message_id: `int` | `None`  
The ID of the system auto moderation message that was posted as a result of the action.

alert_system_message: `Message` | `None`  
The system auto moderation message that was posted as a result of the action, if cached.

content: `str`  
The content of the message that triggered the action.

matched_keyword: `str`  
The word or phrase configured that was matched in the content.

matched_content: `str`  
The substring in the content that was matched.

data: `dict`  
The raw data sent by the [gateway](https://docs.discord.com/developers/events/gateway-events-events#auto-moderation-action-execution).

*Added in 2.5.*

### `RawReactionActionEvent`

```python
class RawReactionActionEvent(data: ReactionActionEvent, emoji: PartialEmoji, event_type: str) -> None
```

Represents the payload for a `on_raw_reaction_add` or `on_raw_reaction_remove` event.

#### Attributes

message_id: `int`  
The message ID that got or lost a reaction.

user_id: `int`  
The user ID who added the reaction or whose reaction was removed.

channel_id: `int`  
The channel ID where the reaction got added or removed.

guild_id: `int` | `None`  
The guild ID where the reaction got added or removed, if applicable.

emoji: `PartialEmoji`  
The custom or unicode emoji being used.

member: `Member` | `None`  
The member who added the reaction. Only available if the reaction occurs within a guild.

*Added in 1.3.*

event_type: `str`  
The event type that triggered this action. Can be `REACTION_ADD` for reaction addition or `REACTION_REMOVE` for reaction removal.

*Added in 1.3.*

burst: `bool`  
Whether this reaction is a burst (super) reaction.

burst_colours: `list` | `None`  
A list of hex codes this reaction can be. Only available if <span class="title-ref">event_type</span> is <span class="title-ref">REACTION_ADD</span> and this emoji has super reactions available.

burst_colors: `list` | `None`  
Alias for `burst_colours`.

type: `ReactionType`  
The type of reaction added.

data: `dict`  
The raw data sent by the [gateway](https://docs.discord.com/developers/events/gateway-events-events#message-reaction-add).

*Added in 2.5.*

### `RawVoiceStateUpdateEvent`

```python
class RawVoiceStateUpdateEvent(*, data: VoiceStateEvent, state: ConnectionState) -> None
```

Represents the payload for a `VoiceProtocol.on_voice_state_update` event.

*Added in 2.7.*

#### Attributes

deaf: `bool`  
Whether the user is guild deafened.

mute: `bool`  
Whether the user is guild muted.

self_mute: `bool`  
Whether the user has muted themselves by their own accord.

self_deaf: `bool`  
Whether the user has deafened themselves by their own accord.

self_stream: `bool`  
Whether the user is currently streaming via the 'Go Live' feature.

self_video: `bool`  
Whether the user is currently broadcasting video.

suppress: `bool`  
Whether the user is suppressed from speaking in a stage channel.

requested_to_speak_at: `datetime.datetime` | `None`  
An aware datetime object that specifies when a member has requested to speak in a stage channel. It will be `None` if they are not requesting to speak anymore or have been accepted to.

afk: `bool`  
Whether the user is connected on the guild's AFK channel.

channel: `VoiceChannel` | `StageChannel` | `None`  
The voice channel that the user is currently connected to. `None` if the user is not currently in a voice channel.

There are certain scenarios in which this is impossible to be `None`.

session_id: `str`  
The voice connection session ID.

guild_id: `int` | `None`  
The guild ID the user channel is from.

channel_id: `int` | `None`  
The channel ID the user is connected to. Or `None` if not connected to any.
