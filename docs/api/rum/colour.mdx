# `rum.colour`

## Classes

### `Colour`

```python
class Colour(value: int)
```

Represents a Colour. This class is similar to a (red, green, blue) `tuple`.

There is an alias for this called Color.

<div class="container operations">

<div class="describe">

x == y

Checks if two colours are equal.

</div>

<div class="describe">

x != y

Checks if two colours are not equal.

</div>

<div class="describe">

hash(x)

Return the colour's hash.

</div>

<div class="describe">

str(x)

Returns the hex format for the colour.

</div>

<div class="describe">

int(x)

Returns the raw colour value.

</div>

</div>

#### Attributes

value: `int`  
The raw integer colour value.

#### `to_rgb()`

```python
to_rgb() -> tuple[int, int, int]
```

Returns an (r, g, b) tuple representing the colour.

#### `resolve_value()`

```python
resolve_value(value: int | Colour | None) -> Self
```

#### `from_rgb()`

```python
from_rgb(r: int, g: int, b: int) -> Self
```

Constructs a `Colour` from an RGB tuple.

#### `from_hsv()`

```python
from_hsv(h: float, s: float, v: float) -> Self
```

Constructs a `Colour` from an HSV tuple.

#### `default()`

```python
default() -> Self
```

A factory method that returns a `Colour` with a value of `0`.

#### `random()`

```python
random(*, seed: int | str | float | bytes | bytearray | None = None) -> Self
```

A factory method that returns a `Colour` with a random hue.

> [!NOTE]
> The random algorithm works by choosing a colour with a random hue but with maxed out saturation and value.

*Added in 1.6.*

#### Parameters

seed: `int` | `str` | `float` | `bytes` | `bytearray` | `None`  
The seed to initialize the RNG with. If `None` is passed the default RNG is used.

*Added in 1.7.*

#### `embed_background()`

```python
embed_background(theme: str = 'dark') -> Self
```

A factory method that returns a `Colour` corresponding to the embed colours on discord clients, with a value of:

- `0x2B2D31` (dark)
- `0xEEEFF1` (light)
- `0x000000` (amoled).

*Added in 2.0.*

#### Parameters

theme: `str`  
The theme colour to apply, must be one of "dark", "light", or "amoled".
