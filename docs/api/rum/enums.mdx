### `RoleType`

```python
class RoleType(*values)
```

Represents the type of role.

This is NOT provided by Discord but is rather computed from `Role.tags`.

*Added in 2.8.*

#### Attributes

NORMAL: `int`  
The role is a normal role.

APPLICATION: `int`  
The role is an application (bot) role.

BOOSTER: `int`  
The role is a guild's booster role.

GUILD_PRODUCT: `int`  
The role is a guild product role.

> [!NOTE]
> This is not possible to determine at times because role tags seem to be missing altogether, notably when a guild product role is fetched. In such cases `Role.type` will be `RoleType.NORMAL` and `Role.tags` will be `None`.

PREMIUM_SUBSCRIPTION_BASE: `int`  
The role is a base subscription role.

> [!NOTE]
> This is not possible to determine currently, will be `.INTEGRATION` if it's a base subscription.

PREMIUM_SUBSCRIPTION_TIER: `int`  
The role is a subscription role.

DRAFT_PREMIUM_SUBSCRIPTION_TIER: `int`  
The role is a draft subscription role.

INTEGRATION: `int`  
The role is an integration role, such as Twitch or YouTube, or a base subscription role.

CONNECTION: `int`  
The role is a guild connections role.

UNKNOWN: `int`  
The role type is unknown.
