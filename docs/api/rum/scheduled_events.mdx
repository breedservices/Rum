#### Attributes

guild: `Guild`  
The guild where the scheduled event is happening.

name: `str`  
The name of the scheduled event.

description: `str` | `None`  
The description of the scheduled event.

start_time: `datetime.datetime`  
The time when the event will start

end_time: `datetime.datetime` | `None`  
The time when the event is supposed to end.

status: `ScheduledEventStatus`  
The status of the scheduled event.

location: `ScheduledEventLocation`  
The location of the event. See `ScheduledEventLocation` for more information.

subscriber_count: `int` | `None`  
The number of users that have marked themselves as interested in the event.

creator_id: `int` | `None`  
The ID of the user who created the event. It may be `None` because events created before October 25th, 2021 haven't had their creators tracked.

creator: `User` | `None`  
The resolved user object of who created the event.

privacy_level: `ScheduledEventPrivacyLevel`  
The privacy level of the event. Currently, the only possible value is `ScheduledEventPrivacyLevel.guild_only`, which is default, so there is no need to use this attribute.

#### `edit()`

```python
edit(*, reason: str | None = None, name: str = ..., description: str = ..., status: int | ScheduledEventStatus = ..., location: str | int | VoiceChannel | StageChannel | ScheduledEventLocation = ..., start_time: datetime.datetime = ..., end_time: datetime.datetime = ..., cover: bytes | None = ..., image: bytes | None = ..., privacy_level: ScheduledEventPrivacyLevel = <ScheduledEventPrivacyLevel.guild_only: 2>) -> ScheduledEvent | None
```

*(coroutine)*

Edits the Scheduled Event's data

All parameters are optional unless `location.type` is `ScheduledEventLocationType.external`, then `end_time` is required.

Will return a new `.ScheduledEvent` object if applicable.

#### Parameters

name: `str`  
The new name of the event.

description: `str`  
The new description of the event.

location: `.ScheduledEventLocation`  
The location of the event.

status: `ScheduledEventStatus`  
The status of the event. It is recommended, however, to use `.start`, `.complete`, and `cancel` to edit statuses instead.

start_time: `datetime.datetime`  
The new starting time for the event.

end_time: `datetime.datetime`  
The new ending time of the event.

privacy_level: `ScheduledEventPrivacyLevel`  
The privacy level of the event. Currently, the only possible value is `ScheduledEventPrivacyLevel.guild_only`, which is default, so there is no need to change this parameter.

reason: `str` | `None`  
The reason to show in the audit log.

image: `bytes` | `None`  
The cover image of the scheduled event.

cover: `bytes` | `None`  
The cover image of the scheduled event.

#### `subscribers()`

```python
subscribers(*, limit: int | None = 100, as_member: bool = False, before: Snowflake | datetime.datetime | None = None, after: Snowflake | datetime.datetime | None = None) -> ScheduledEventSubscribersIterator
```

Returns an `AsyncIterator` representing the users or members subscribed to the event.

The `after` and `before` parameters must represent member or user objects and meet the `abc.Snowflake` abc.

> [!NOTE]
> Even is `as_member` is set to `True`, if the user is outside the guild, it will be a `User` object.

#### Parameters

limit: `int` | `None`  
The maximum number of results to return.

as_member: `bool` | `None`  
Whether to fetch `Member` objects instead of user objects. There may still be `User` objects if the user is outside the guild.

before: `abc.Snowflake` | `datetime.datetime` | `None`  
Retrieves users before this date or object. If a datetime is provided, it is recommended to use a UTC aware datetime. If the datetime is naive, it is assumed to be local time.

after: `abc.Snowflake` | `datetime.datetime` | `None`  
Retrieves users after this date or object. If a datetime is provided, it is recommended to use a UTC aware datetime. If the datetime is naive, it is assumed to be local time.

#### Yields

`User` | `Member`  
The subscribed `Member`. If `as_member` is set to `False` or the user is outside the guild, it will be a `User` object.

#### Raises

HTTPException  
Fetching the subscribed users failed.

#### Examples

Usage :

    async for user in event.subscribers(limit=100):
        print(user.name)

Flattening into a list: :

    users = await event.subscribers(limit=100).flatten()
    # users is now a list of User...

Getting members instead of user objects: :

    async for member in event.subscribers(limit=100, as_member=True):
        print(member.display_name)
