# `rum.sticker`

## Classes

### `GuildSticker`

```python
class GuildSticker(*, state: ConnectionState, data: StickerPayload) -> None
```

Represents a sticker that belongs to a guild.

*Added in 2.0.*

<div class="container operations">

<div class="describe">

str(x)

Returns the name of the sticker.

</div>

<div class="describe">

x == y

Checks if the sticker is equal to another sticker.

</div>

<div class="describe">

x != y

Checks if the sticker is not equal to another sticker.

</div>

</div>

#### Attributes

name: `str`  
The sticker's name.

id: `int`  
The id of the sticker.

description: `str`  
The description of the sticker.

format: `StickerFormatType`  
The format for the sticker's image.

available: `bool`  
Whether this sticker is available for use.

guild_id: `int`  
The ID of the guild that this sticker is from.

user: `User` | `None`  
The user that created this sticker. This can only be retrieved using `Guild.fetch_sticker` and having the `Permissions.manage_emojis_and_stickers` permission.

emoji: `str`  
The name of a unicode emoji that represents this sticker.

#### `edit()`

```python
edit(*, name: str = ..., description: str = ..., emoji: str = ..., reason: str | None = None) -> GuildSticker
```

*(coroutine)*

Edits a `GuildSticker` for the guild.

#### Parameters

name: `str`  
The sticker's new name. Must be at least 2 characters.

description: `str` | `None`  
The sticker's new description. Can be `None`.

emoji: `str`  
The name of a unicode emoji that represents the sticker's expression.

reason: `str`  
The reason for editing this sticker. Shows up on the audit log.

#### Returns

`GuildSticker`  
The newly modified sticker.

#### Raises

Forbidden  
You are not allowed to edit stickers.

HTTPException  
An error occurred editing the sticker.

#### `delete()`

```python
delete(*, reason: str | None = None) -> None
```

*(coroutine)*

Deletes the custom `Sticker` from the guild.

You must have `Permissions.manage_emojis_and_stickers` permission to do this.

#### Parameters

reason: `str` | `None`  
The reason for deleting this sticker. Shows up on the audit log.

#### Raises

Forbidden  
You are not allowed to delete stickers.

HTTPException  
An error occurred deleting the sticker.
